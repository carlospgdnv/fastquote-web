# FastQuote Web (Phase 1 Frontend MVP)

Web-based quotation and purchase order management system.

## Stack

- Next.js 14 (App Router)
- TypeScript
- TailwindCSS
- shadcn/ui
- React Hook Form + Zod
- TanStack Query
- @react-pdf/renderer

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Scope (Phase 1)

- Dashboard
- Quotes (create/edit with totals)
- Purchase Orders (list + create)
- Products (list)
- Suppliers (list)
- Settings (placeholder)
- Frontend-only mock data

## Notes

This is intentionally frontend-only and prepared for future backend integration.
